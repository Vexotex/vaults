Während eine (G)UI für die manuelle Interaktion gedacht ist, stellt eine API die programmatische Schnittstelle zur Anwendung her.

Wenn es sich bei der Anwendung um einen Service handelt (webservice, deamon), so besteht die API normalerweise aus endpoints, welche man ansprechen kann.

Wenn es sich bei der Anwendung um eine Library handelt, so besteht die API normalerweise aus einem header, welcher bestimmte Funktionen frei gibt.

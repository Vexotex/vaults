Generell ist die UI eine der wichtigsten Komponenten. Sie sollte immer zuerst designed werden, da es sehr einfach ist, hier mit dem Kunden über seine Wünsche und Ansprüche zu reden. Außerdem gibt sie gute Ansätze für den Rest des Designs.

Zwei Mögliche Arten hier sind die GUI (Graphical user interface, Website, etc.) und CLI (command line interface, Python, etc.)

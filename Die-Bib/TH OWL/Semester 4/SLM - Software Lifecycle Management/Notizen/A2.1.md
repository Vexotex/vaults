# Taschenrechner für Polynome 2. und 3. Grades
Es soll ein Taschenrechner entwickelt werden, der Polynome 2. und 3. Grades lösen kann. Dafür ist zuerst ein Programm zu schreiben, welche diesen Lösungsprozess algorithmisch umsetzt. Das wäre für Polynome 2. Grades eine Implementierung der pq-Formel und für Polynome 3. Grades eine Implementierung der Cardanischen Formel mit Betrachtung und Handling von Fällen mit negativen Werten unter den Quadratwurzeln. Hier können dann die komplexen Lösungen berechnet werden. Desweiteren muss dieses Programm dann auf Hardware umgesetzt werden, also auf sowas wie einem Pi, an welchem eine Möglichkeit für User-Input eingerichtet werden muss. Dieser eingegebene User Input sollte vor Übergabe an das Programm kontrolliert und standardisiert werden.

Vorstellung:
- Eingabefeld für Polynom
- —> klare Eingabestruktur muss vorgegeben werden
- Ausgabe erfolgt in einzelnen Schritten für den Lerneffekt
- mittlerer Aufwand
- —> Rechenmethoden bereits bewährt
- —> Erweiterbarkeit (komplexe Lösungen, weitere Verfahren, …)
Ablauf:
- Eingabeformat festlegen
- verschiedene Rechenmethoden implementieren
- Ausgabe der Schritte Formatieren
Technik
- mathematisch alles gegeben
- HW —> (geregelter) Input

# Umgebung
isolierter batteriebetriebener Microcontroller. 
einfaches Linux-Betriebssystem mit nur einem Programm, dass automatiisch beim boot startet

Leute die öfter on-the-fly ein polynom berechnen müssen.

# Titel: ASCII-Wimmelbild
Das angedachte Projekt ist ein Konsolenbasiertes ASCII-Wimmelbildspiel. In derKonsole wird eine Fläche mit verschiedenen zufällig generierten ASCII Zeichen gefüllt, von denen eines das gesuchte ASCII Zeichen ist . Die Fläche ist als zwei dimensionalerGraph zu verstehen, der mithilfe von Indizes an beiden Kanten beschriftet ist. Über
diese Indizes kann ein Feld wie in Schachnotation ( z.B. A7 ) ausgewählt werden, in dem das gesuchte ASCII Zeichen gefunden wurde. Diese Notation kann dann eingegeben werden und wird vom Programm mit der tatsächlichen Position verglichen. Darauf folgt eine Rückmeldung an den Nutzer.
Als „must have“ Kriterien sind hier folgende aufzufassen:
- Zufällige Generierung des Spielfeldes mit einer (!) Platzierung des gesuchten ASCII Zeichens ( 50 Zeilen; 2h )
- Formatierte Ausgabe des Spielfeldes mit Beschriftung ( 30 Zeilen ; 3h)
- User-Input einlesen und richtige Platzierung zum Auswerten speichern und vergleichen ( 20 Zeilen; 1h )
- Ergebnis ausgeben ( 5 Zeilen ; 0.5 h )
„can have“ Kriterien wären hier mögliche Erweiterungen:
- Größe des Spielfeldes variabel durch Nutzereingabe auswählen lassen ( 40 Zeilen; 2h )
- Schwierigkeit durch Abstand zwischen den Zeichen einstellbar gestalten ( 50 Zeilen; 3h )
- Mehrere Vorkommnisse des gesuchten Zeichens einrichten; Für Erfolg müssen alle gefunden werden ( 20 Zeilen; 2h )
- Highscore einführen – wie oft hintereinander wurde das Zeichen richtig gefunden ( 10 Zeilen; 0.5 h)
- Zeitbegrenzung für Suche geben ( 30 Zeilen ; 3h ) Das Projekt sollte folgende Punkte nicht umfassen („Boundaries“):
- Entwicklung eines GUI in dem die Felder anklickbar sind, anstatt einen simplen Schrift-Input zu nutzen

Angedacht wäre eine Umsetzung in C, die Programmiersprache ist allerdings nicht besonders entscheidend, da im Grunde nur Ausgabe und Eingabemöglichkeiten zur Command Line bestehen müssen.

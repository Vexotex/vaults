## A4
Softwareidee: Lokaler Media-/Asset-Manager für 3D-Modelle
Viele Entwickler und Kreative besitzen eine große Anzahl an digitalen Assets wie 3D-
Modelle, Texturen oder Animationen. Diese liegen oft unsortiert in verschiedenen Ordnern,
wodurch das Wiederfinden einzelner Dateien zeitaufwendig und ineffizient wird.
Die geplante Software soll dieses Problem lösen, indem sie als zentraler Media-Manager
für lokale Dateien dient. Der Nutzer kann einen oder mehrere Ordner angeben, in denen
sich seine Assets befinden. Ein integrierter Parser durchsucht diese Verzeichnisse
automatisch, erkennt relevante Dateien (z. B. .obj, .fbx, texturen) und überführt deren
Informationen in eine Datenbank.
Zusätzlich wird für jedes Asset automatisch ein Vorschaubild generiert, um eine visuelle
Navigation zu ermöglichen. Diese Vorschau kann beispielsweise durch ein Rendering des
3D-Modells, via Blender mit CLI oder Custom Addon, erstellt werden.
Die Verwaltung erfolgt über ein webbasiertes Frontend, das lokal im Browser läuft. Dort
werden alle Assets übersichtlich angezeigt. Der Nutzer kann Dateien benennen, mit Tags
versehen und nach verschiedenen Kriterien filtern oder durchsuchen.
